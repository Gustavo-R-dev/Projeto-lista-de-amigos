# 🚀 Projeto Lista de Amigos — Autenticação e Sessão em PHP

## 📌 Sobre o Projeto
Aplicação web desenvolvida em PHP e MySQL que implementa sistema de login, controle de sessão para proteção de páginas via URL e modularização de código.

## 📂 Arquivos no Repositório
- `Apresentação Técnica do Projeto — Sistema Lista de Amigos.pdf`: Slides completos com a explicação técnica da aplicação. (obs: infelizmente os vídeos que estariam nos slides viraram imagens estáticas quando eu baixei em formato pdf)
- Códigos-fonte em PHP e Scripts SQL do Banco de Dados.

## 🛠️ Tecnologias Utilizadas
- HTML5 & W3.CSS
- PHP
- MySQL
